Assignment overview 
In this assignment you will get a chance to play with real-world applications of GPGPU 
programming. You will need to implement two basic image-processing algorithms - one for 
sharpening and one for noise removal - using the Nvidia Warp API. Each algorithm should be 
implemented using one or more dedicated kernels. 
Implementation 
For sharpening, use unsharp masking described in class. For noise removal, you can pick one 
of the Gaussian or median ﬁltering algorithms described in Lecture 17. 
Your executable will run as follows:
python3 a3.py algType kernSize param inFileName outFileName
where:
-algType is either -s (sharpen) or -n (noise removal)
-kernSize is the kernel size - e.g. 3 for 3x3, 5 for 5x5, etc. It must always be positive and 
odd.
-param is the additional numerical parameter that the algorithm needs - e.g. the scaling value 
k for unsharp masking or sigma for the Gaussian. If your algorithm doesn't need any 
additional parameters once it knows the kernel size, just pass some dummy value here (e.g. 
0)
-inFileName is the name of the input image ﬁle
-outFileName is the name of the output image ﬁle 
Your algorithm must work with greyscale (PIL mode “L”) and colour (PIL modes “RGB” and 
“RGBA”) images. We will only test your code with these three modes. For RGBA images, leave 
the alpha channel unchanged. The output image must have the same mode as the input image. 
You will use the PIL image library. A stub that shows you how to open an image using PIL, 
check its mode, pass it to a Warp kernel and save the result has been provided for you.
Report 
In addition to the implementation, provide a report document in which you:
-Provide any information that we might need when running your code
-Describe which algorithms you have implemented
-Describe the test cases you have used to validate algorithm correctness - i.e. that it aﬀects 
an image the way it is supposed to. Include examples in the report and explain why you 
used them.
-Explain how you have implemented the kernel(s) for this algorithm using the Warp API. You 
can paste the code into the document so you can more clearly explain it.

Bonus marks (up to 10 marks)
1.Alternative sharpening: implement a sharpening algorithm other than unsharp masking. 
This algorithm cannot be based on anything described in class (5 marks).
2.Alternative denoising: implement a noise removal algorithm that is not based on what we

To get each of these bonus marks, you must do the following:
-Clearly describe the algorithm in your report and state where you found its description
-Clearly demonstrate, with multiple visual examples, that the algorithm you have implemented

-If you are implementing a denoising algorithm, demonstrate with sample images that it
