===== PAGE 4 =====
Filters
• Filtering is a fundamental operation that we will use 
• Low-pass filter (LPF): image smoothing (de-noising) 
• High-pass filter (HPF): difference between image and low-pass filtering. 
• High-boost filter: part of high-pass added to image. 
• Low- and High- refer to filter action in frequency domain. 
• e.g. Low-pass means that we "pass" low-frequency components 
•
So we can call it a "high-cut filter" 
•
Large, sudden - i.e. closely spaced - fluctuations in pixel intensity are removed 
•
These can be undesirable (noise) or desirable (fine detail) 

===== PAGE 5 =====
Image sharpening
• Image sharpening relies on high-pass filtering, which allows high spatial frequencies to 
remain unchanged, but suppresses low frequencies 
• A high-pass filter has the effect of preserving sudden variations in intensity, such as those 
that occur at the boundaries of objects, but suppressing more gradual variations.

===== PAGE 7 =====
Simple sharpening
• How it works: 
•
When the kernel is over an area of constant or slow-changing intensity values the result of the 
convolution is zero (or small). 
•
When the intensity values vary rapidly within a neighbourhood, the result of the convolution is a 
large number. 
• Caveats of sharpening 
•
Image sharpening makes noise more prominent - noise has a strong high-frequency component 
•
In practice, we often want to remove the noise before sharpening

===== PAGE 8 =====
Unsharp masking
• Introduced by Schreiber in 1970 for improving the quality of wirephoto pictures for 
newspapers.  
• Based on the principle of photographic masking whereby a low-contrast positive 
transparency is made of the original negative. 
• The mask is then “sandwiched” with the negative and the amalgam used to produce the final 
print.
Schreiber, W.F., “Wirephoto quality improvement by unsharp masking”, Pattern Recognition, 1970, V.2, pp.117-121.

===== PAGE 9 =====
Unsharp masking
• Unsharp masking relies on subtracting from an image a “blurred” version of that image 
(thereby removing the low spatial frequencies). 
• A common way of sharpening an image. 
• Sometimes called a high-boost filter, if the parameter k (which we see later) is > 1. 
• Unlike most of the previously discussed methods, it is a multi-step approach

===== PAGE 21 =====
De-noising (noise suppression) algorithms
• There are many different types of noise suppression algorithms. 
• Generally, noise suppression filters are various types of smoothing (low-pass) filters 
• Two primary categories: mean-based and order-statistic based filters

===== PAGE 22 =====
Averaging = smoothing = noise suppression
• The simplest way to get rid of noise is to perform some form of neighbourhood averaging.  
• Image smoothing, or low-pass filtering. 
• Known as mean, sliding mean, or box filter. 
• It has the effect of smoothing or blurring the image, reducing noise but obscuring fine detail 
•
Essentially, it is the opposite of sharpening

===== PAGE 23 =====
Image smoothing
• The filter replaces the value of every pixel in an image by the average of the intensity values in 
the neighbourhood defined by the kernel. 
• The resulting image has reduced “sharp” transitions in the intensity values. 
• Noise consists of sharp transitions ➾ noise reduction 
• Edges are also characterized by sharp transitions in intensities, so smoothing filters blur 
edges.

===== PAGE 34 =====
Rank filtering
• Non-linear filters known collectively as order statistic filters or rank filters 
•
These include the median value, lower and upper quartiles, etc.. 
• Compile a list of intensity values in the neighbourhood of a given pixel, sort this list into 
ascending order 
• Then select a value from a particular position in the list to use as the new value for the pixel.

===== PAGE 35 =====
Median filtering
• Select the middle-ranked value (median) from a neighbourhood to replace the pixel (i, j) 
• Used to eliminate impulse noise 
•
Median filtering removes impulse noise effectively when the noisy pixels occupy less than half 
the neighbourhood - the median then comes from the "clean" majority. 
•
The same mechanism cuts both ways: genuine small features (thin lines, small objects) that 
occupy less than half the neighbourhood are removed too, not just noise. 
• Median-filtering is non-specific 
•
Any structure that occupies less than half of the filter's neighbourhood will tend to be eliminated
