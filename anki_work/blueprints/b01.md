## 01 Hardware / locality / Flynn (Ch2 §§2.1–2.3) — cram

Predicted share of M2: 2–4 of 27 questions. High-yield only (≤12 cards).

1. [high] Spatial vs temporal locality. (M2 guide; Ch2 p.22)
   Full-mark: Spatial = nearby address next; temporal = same location reused soon.
2. [high] Why flat contiguous arrays matter for locality and transfers. (M2 guide Data layout)
   Full-mark: Neighbouring addresses → spatial locality / cache-line reuse; one block as one MPI message or GPU copy.
3. [high] C row-major: which nest for `y[i]+=A[i][j]*x[j]` is faster? (Ch2 pp.24–25)
   Full-mark: Outer `i` inner `j` walks rows contiguously; column-stride order thrashes.
4. [high] Define Flynn SISD, SIMD, MISD, MIMD. (M2 guide; Ch2 §2.3.1)
   Full-mark: SISD 1I/1D; SIMD 1I/manyD; MISD manyI/1D; MIMD manyI/manyD.
5. [high] How vector processors work; pros and cons. (M2 guide; Ch2 pp.32–33)
   Full-mark: Vector registers/instructions on arrays (vs scalars). Pros: vectorizing compilers, high bandwidth, every loaded item used. Cons: irregular data, vector-length scalability, expensive long-vector HW.
6. [high] Shared-memory vs distributed-memory MIMD coordination. (Ch2 §2.3.3)
   Full-mark: Shared = implicit via shared data; distributed = private memory + explicit messages.
